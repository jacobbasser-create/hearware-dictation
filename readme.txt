HearWare Dictation Engine

This package contains the HearWare local dictation application.

Installation:
Extract the complete HearWareDictation folder to:

C:\HearWare\

The resulting folder structure must be:

C:\HearWare\HearWareDictation\HearWareDictation.exe
C:\HearWare\HearWareDictation\_internal\

The executable and _internal folder must remain together.

HearWare manages the application installation and updates.
